## 共用底座与范围

- `base.css` 是正式 `ui/index.html` 的样式快照，省去默认主题不用的字体数据；`preview.html` 沿用正式 DOM、图标和概览渲染函数。
- 只保留 `layered` 排版。各皮肤覆盖只含颜色、背景、边框颜色、圆角、阴影、模糊与不位移的悬停反馈，不覆盖 display、网格、字体、宽高、间距、顺序或位置。
- 所有候选使用相同示例：3 个 Key、10 个 Key 模型、12 个官方模型、3 个同名模型，当前查看主力 Key 的 7 个模型。没有真实 Key、账号、私有链接或本机数据路径。
- 小样不注册业务操作事件、不调用 API、不读取本机配置。它只用于选皮肤，不代表功能验收完成。
- 目标平台仍为 macOS WKWebView 与 Windows WebView2；原生窗口、标题栏、字体渲染与系统控件不在本轮皮肤改动内。
