# UI 施工参数 · reference-v2

## 参考与计量方法

- 唯一已确认效果图：[ui-reference.png](ui-reference.png)。概览按它还原；Key、优先级、设置沿用同一套材质，并在下面明确各自布局。
- 参考图客户端为 `(44,85)–(1444,992)`，尺寸 **1400×907 px**。坐标原点是客户端左上角；外部壁纸、窗口阴影和原生标题栏不计入网页。
- 图中边界、色块、图标尺寸是像素采样/量测。字体大小、透明度、模糊、阴影和曲面控制点是拟合值，不能由一张合成位图唯一反解；以实现截图继续校准。
- CSS 用 `--u:clamp(.84px,.07142857vw,1px)` 作为一个参考像素；1400 宽时 1，1228 宽时 .8771，1180 宽时 .8429。尺寸、字号跟随它；边框始终 1 个 CSS px。1100/900/740 断点采用下面的适配规则。
- 参考图里的示例数字、来源和模型不写入产品：实际界面继续读取后台数据。

| 其他页分组 tile / glyph | 44u / 26u；共享色阶、高光、阴影 |
| 操作图标 | 24u、线宽 2；主结构 tile 用白色实体 glyph，操作用线性 glyph |
| 青基底 | `#2EC3F5 → #0FA1DB` |
| 紫基底 | `#7F65F9 → #5243E0` |
| 蓝基底 | `#4D8FFD → #2B64F3` |
| 橙基底 | `#F3A542 → #D27C24` |
| 品牌 / 页面标题 | 44u / 40u，700；品牌白色，标题墨色 |
| 分组标题 / 来源标题 | 26u / 28u，650 |
| 来源名称 | 24u，550；长名称自然换行 |
| 导航 / 操作 / 表格正文 | 22u / 22u / 20u；数据行高 52u |
| 正文 / 辅助 / 表头 | 20u / 18u / 18u；辅助字号最低 13px |
| 指标数字 / 标签 | 48u / 20u；数字 700、行高 1.05；标签墨色 |

字体沿用 macOS / Windows 系统 UI 字体栈，不新增网络字体或图标依赖。tile 用内联 SVG，曲面用本地 SVG。

Key 的圆环用偶奇填充，杆/齿为 SVG 24×24 视口里的 4 单位白色圆头笔画；模型上层菱形用二次贝塞尔圆角，下层为 2.8 单位圆头/圆拐角笔画。云为 `#F8FCFF` 实体 + 2.2 单位同色蓝勾。实际笔画宽度随 glyph 尺寸缩放；确切路径集中在 `ui/index.html` 的 `TILE_ICONS`，不在运行时随机生成。圆润轮廓与柔光一起复核，不能把“fill=white”当作形状还原。

校准依据：初轮蓝 tile 顶边为 `#B3CEFE`，参考 `#5A9DFC`；青为 `#A6E4FA`，参考 `#40D1F7`。初轮青接触阴影 `#D3EEF9`，参考 `#C1E8FA`。因此取消硬白边、增加分层同色阴影，并降低统计面顶部白叠层。上述参数取代初稿 .48 白边/.65 内高光。

第二轮曲面校准：`x10,y555→560` 的 R 通道初轮跳变 52，参考只有 2；主体必须羽化。`(265,530)` 初轮位于贝塞尔外缘之外，G 比参考低55，因此外侧控制点由254/148移到295/168，将此点纳入青色曲面。图标顶下6px仍过白，故径向白光从 .16 下调 .06。

## 6. 小窗口、深色和验收

- ≤1100：Key 列表先横排，主区仍用公共 gutter=20px；侧栏缩到 208px，导航保持可读。
- ≤900 或高≤700：概览操作和指标各两列；来源面独立高度 500u；页面允许纵向滚动。
- ≤740：侧栏 72px，仅保留 36px tile 和小 logo；gutter=12px；来源列表横排且长名称顶部对齐，可横/纵向滚动；表格保持横向滚动。
- 四页 `#page` 都使用 `scrollbar-gutter:stable`。26u 总右边距**包含**系统滚动条槽；渲染/调整窗口时测量 `offsetWidth-clientWidth`，用 CSS 右内边距减去该宽度（最低 0），并记录日志。这样常驻和覆盖式滚动条都有相同白面右边缘，不通过隐藏系统滚动条掩盖差异。
- 深色无独立确认图：复用上述尺寸、图形、明暗层次；背景 `#111827`、工作区 `#1B2638`、边 `#354761`、文字 `#EDF3FC`，降低侧栏曲面透明度及玻璃高光，不照搬浅色白底。
- 用合成业务数据渲染 1400×907 客户端，匹配参考的来源、数字和表格行数，逐项检查坐标、采样色、曲面、图标尺寸、高光。真实数据的行数与标签不用于像素差异评分。
- 另外检查 1228×820、1180×820、900×700、640×640；四页白面右边缘偏差≤1px；主尺寸目标偏差≤2px；参考色块平均 RGB 通道误差目标≤12；阴影/柔光区域需实际截图人工对照，不以“没有溢出”代替视觉验收。
- 检查键盘、轮询、弹窗和原生桥接的已有回归。不启动真实路由，不调用 computeruse，不打包。Chromium 验证不能替代两端原生 WebView 实机验收。
