# UI 施工参数 · I「模型字典」

## 基准与范围

- 用户已选 I，并授权删除概览的最近事件、补齐排版后直接施工；不再重做三套方案。
- 批准后的施工参考：[核心效果图](ui-implementation-I/i-overview-approved.png)、[参考 HTML](ui-exploration/2026-10-15/round-3/i-overview-approved.html)；方向来源：[I 原稿](ui-exploration/2026-10-15/round-3/i-model-lexicon.html)。客户端基准为 **1180 × 820 CSS px**，原生标题栏、系统窗口按钮和窗口阴影不计入页面。
- 原稿的 `108 / 566 / 82 / 64` 四段改为 **108 / 648 / 64**；删除 82px 事件带，把空间交给模型目录。字号与 I 的字典式排版保持一致。
- 四页共用一套 HTML；保留 Python 服务、Go 外壳、现有接口、配置和操作流程。本次不改服务和打包代码，不制作安装包。
- 本文件已同步 [正式 CSS](../ui/index.html)，**代码回归与独立截图评审通过**；完整实际参数以 CSS 为准。已有 `UI施工参数.md` 是上一版资料，不用于本次施工，也不改写它。

## 3. 四页施工

| 页面 | 内容组织 | 必须保留 |
| --- | --- | --- |
| 概览 | 左边模型目录；右边来源索引与路由服务；顶部显示运行/接管状态和 4 项数量 | 官方模型、Key 模型、已配置 Key、同名模型；来源选择；刷新模型、启用路由、停止路由、切回官方；版本与任务反馈 |
| Key 与模型 | 左主区编辑所选来源，右 270px 来源索引；主要模型目录延续大字与细线 | 添加、编辑、删除 Key；拉取 Key/官方模型；上游、脱敏密钥与最近拉取时间；搜索、全选、清空、保存勾选；接入勾选、图片输入开关、接入方式与状态 |
| 路由优先级 | 占满可滚动工作区；标题、保存与说明在表格上方；保持列对齐 | 每个模型的来源下拉、其他来源、说明与保存优先级；默认规则、官方覆盖提示、保存后刷新提示 |
| 设置 | 左主设置区；右 270px 日志与诊断区；用标题与分隔线分组 | 自启动、macOS 隐藏程序坞、接管开关、官方状态、服务状态、管理端口与保存、浅/深色主题、打开日志；诊断中的路由地址、数据目录、配置文件、自启动命令、版本和平台 |

Key 页大字只用于模型名称，表格行高 1.15。勾选列、图片列、协议与状态使用 UI 字体；不能挤压复选框或保存按钮。Key 模型表最小宽 690px（接入/图片/方式/状态列为 48/80/96/74px），优先级表最小宽 700px，必要横向滚动只发生在表格内部。来源列表与工作区顺序改成左工作、右索引，不改变来源选择逻辑。

优先级表格单元格上下内距为 8px，来源下拉最小高 42px；基准窗口中七行完整显示。概览刷新图标使用 `stroke-linecap:butt`、`stroke-linejoin:miter`，匹配原 I 的线端与转角；其他图标沿用圆线端。

添加/编辑弹窗沿用名称、密码输入、上游地址、取消、保存和错误提示；宽度约 500px，最大宽度为窗口减 48px，最大高度为窗口减 48px，内部可滚动。继续保留删除确认、Escape 关闭、Tab 焦点限制和关闭后焦点归还。

主页最近事件彻底退出页面布局；后台事件与日志能力保留。删除事件带不增加新的统计、监控或会话功能。

## 4. 适配与长内容

| 视口 | 参数 / 行为 |
| --- | --- |
| 1180×820 | 上述基准；主区 648px；7 行模型高 72px，字号 44px |
| 1000px 宽 | 保持 32px 外边距、270px 右列、44px 列距；模型字号由 clamp 收缩；其余全局尺寸保持基准 |
| ≤980px（含 900px） | `--index-width:230px`、`--column-gap:24px`、`--header-gap:20px`、`--stats-gap:18px`、`--brand-size:54px`、`--count-size:24px`；Key 搜索独占一行，Key 模型名 32px，面板标题间距 8px，设置行间距 12px |
| ≤800px | 左右区纵排；`--page-pad-x:24px`、`--header-gap:14px`、`--stats-gap:12px`、`--brand-size:44px`、`--brand-label-size:20px`、`--count-size:21px`、`--nav-gap:24px`；概览模型区最小高 560px，来源列表最高 240px；Key 主区最小高 500px、来源区最小高 260px；隐藏导航右侧辅助文字 |
| 高度变化 / 系统缩放 | 顶部 108px、底部 64px不变，主区随可用空间变化；不足 7 行时滚动，多于 7 行时展示真实数据 |

长模型名首先减字号、允许换行或增高行；使用 `min-width:0` 与 `overflow-wrap:anywhere`，完整名称可读。不能用强制单行把接入方式、复选框、下拉框或保存按钮挤出工作区。长来源名和路径自然换行；表格内部可横向滚动，整页不产生横向滚动。

macOS WKWebView 与 Windows WebView2 共用页面；保留平台原生标题栏、窗口控制、菜单栏/托盘和文件交互。系统 UI 字体、滚动条、原生 select 与字体抗锯齿允许平台差异，不能模拟另一平台窗口按钮。

## 5. 状态与交互参数

| 状态 | 施工规则 |
| --- | --- |
| 普通 / hover | 按钮最小高 42px、13px、左右内距 12px（sm 为 10px）；普通透明纸底与 1px 墨色边，hover 使用对应实色；主操作墨底纸色字；没有额外自定义按下动画 |
| 来源选中 | 朱红底与对应前景；`aria-pressed` 同步；名称、状态与模型数量完整显示 |
| 导航当前页 | 14px、700；距底 14px 的 2px 纸色 `--bg` 下划线；保留 `aria-current="page"` |
| 加载 / 忙碌 | 使用真实后台任务文本与既有转圈；相关操作 disabled，保留标签；首次加载说明正在读取，不能展示虚构数量 |
| 禁用 | 使用禁用文字/边线，鼠标不触发 hover 底色；真实 disabled 属性和已有条件保留 |
| 空状态 | 在所属目录或表格里说明“未拉取”或“没有匹配”；保留到 Key 页/拉取/调整搜索的既有恢复方式 |
| 错误 / 成功 | 保留行内错误、任务反馈和 toast；错误朱红、成功语义色，均有文字；toast 避开底部导航，底距至少 80px |
| 键盘焦点 | `focus-visible` 3px 朱红外框、offset 3px；朱红导航上使用对比前景；控件不能因裁切隐藏焦点 |
| 表单 / 开关 | 输入框与下拉最小 42px、内距 8px 10px；复选框 18px；开关直角 44×26px，内方块 18px、内距 3px；保留可访问名称、`role="switch"` 与 `aria-checked`；主题按钮 40px，来源区“添加”32px |
| 动效 | 唯一忙碌动画为 12px 转圈、2px 边线、`sp .7s linear infinite`；没有装饰过渡；`prefers-reduced-motion:reduce` 下禁用动画和过渡 |
| 强制颜色模式 | 选中来源显示 2px Highlight 轮廓、offset -2px；当前导航下划线；选中开关使用 Highlight 边框与方块 |

轮询期间保留搜索词、模型勾选草稿、优先级草稿、当前来源、焦点与滚动位置。操作仍执行原有保存/刷新流程；“已配置”只代表有密钥，“已登录”只代表本机登录检测，均不等于远端健康。正文固定来源，失败不自动切换。

## 6. 素材交付与验收

- 字体来源：`ui-exploration/2026-10-15/round-3/fonts/InstrumentSerif-Regular.ttf`；许可：同目录 `InstrumentSerif-OFL.txt`，SIL OFL 1.1。
- 正式 `ui/index.html` 已内嵌同一字体 data URL，并以 `text/plain` 保留版权与完整 OFL 许可；文档不复制字体编码。现有 macOS/Windows 打包流程复制 HTML 时即可携带字体与许可，不新增网络请求或打包分支。
- 首先对照 1180×820 核心图检查品牌、顶部数量、左模型右来源、72px 模型行和朱红导航；再检查 1000/900px 宽、长名称、忙碌与空状态、深色主题。
- 功能只验本次触及的核心路径：来源切换、Key 操作与模型勾选/搜索、优先级下拉与保存、设置/主题、轮询保留编辑状态。代码测试按 AGENTS 指定测试子 agent；computeruse 必须先获用户授权。
- Node UI 行为回归、JS/Python 语法检查和管理服务 46 项测试通过；四页、深色、900×700 窄窗、Key 弹窗的独立截图评审通过。
- 概览与批准图同为 1180×820，主要几何边界一致；0.936751% 像素存在差异，其中 9059 个像素的最大 RGB 通道差仅为 1，另 5 个位于刷新图标、最大差为 6。不能据此宣称逐像素完全相同。
- 截图使用隔离 Chrome 与虚构 API 状态，不读取真实密钥或连接真实上游。原生 WKWebView/WebView2、Windows 实机和安装包未验证，本次未打包；详见 [验收记录](ui-implementation-I/README.md)。
