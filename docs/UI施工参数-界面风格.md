### 四页延展与窄窗

- 概览按双浮层＋126px dock。Key 与模型将编辑区放在主浮层，来源继续横排 **148px dock**，给标题、“添加”按钮和完整66px来源项留空间；Key操作和搜索紧跟标题，表格内部滚动。≤980px时编辑区与dock共同最小高650px，由主区纵向滚动，避免表格被压到零高。优先级使用横向主浮层；设置使用主设置/日志诊断两个浮层，均沿用 rail、标题区与页脚；非概览页顶部保留真实服务/接管状态。
- ≤980px：rail 仍为 88px；主区内距 20px、列距 14px、服务层 230px；统计项间距 18px；Key 搜索可独占一行，dock 来源维持可读宽度并允许其内部横向滚动。
- ≤800px：双浮层纵排，模型层最小460px、服务层最小260px、概览dock最小126px；dock保留横向来源语义，用至少180px的来源项内部横向滚动，不能裁掉操作按钮。Key主编辑区最小480px、dock148px；主区纵向滚动、rail固定，导航标签仍可读。
- 高度不足时核心工作区滚动，浮层最小高度由真实内容决定；不通过缩小正文字号塞入。Key 模型表最小宽 690px、优先级表最小宽 700px，横向滚动限于表格内部。

## 5. 共用交互与状态

| 项目 | 固定规则 |
| --- | --- |
| 设置选项 | 标签“界面风格”；固定顺序“默认主题 / 工作索引 / 模型字典”；使用现有表单或分段选择，分段最小高 40px；标签不能用 F/C/I 替代；窄窗允许换行 |
| 即时切换 | 选择后立即作用于四页与共用按钮、表单、弹窗、提示；保存状态、失败提示沿用设置机制；保存失败回到已保存值并保留错误文字 |
| 风格保存中的焦点例外 | 风格分段按钮使用 `aria-disabled="true"`，保留可聚焦节点；透明度 `.65`、`cursor:wait`，保存锁阻止重复操作，避免原生 disabled 导致焦点退回 body；保存结束后恢复属性和反馈。该例外只用于风格保存，路由与后台任务操作继续使用原生 disabled |
| 状态保留 | 切换不调用路由启停、接管或模型来源动作；保留当前页、来源、模型/图片勾选草稿、优先级草稿、搜索、端口未保存值、弹窗输入、焦点与合理滚动位置 |
| 设置页往返 | 通过导航进入设置、切换风格后再返回，仍保留模型搜索与优先级草稿；导航不清空这些未保存状态 |
| 首屏与持久化 | 复用现有 settings API 和主题首屏缓存机制；缓存与后台的风格只接受三个白名单值；读取旧配置回退 `lexicon`；后端返回后以真实配置为准 |
| 按钮和表单 | 不改变业务禁用条件；表格输入和保存按钮最小高沿用现有 42px，F/C 概览紧凑操作按各自参考尺寸；必要的文字标签与可访问名称完整保留 |
| 焦点 | `focus-visible` 3px、offset 3px；F 蓝色、C 绿色、I 朱红；深色使用对应亮色，彩色底上用对比前景；不能被 overflow 裁切 |
| 错误与加载 | 复用现有真实任务与 toast，错误/成功均有文字；加载时不伪造模型数；除上述风格保存焦点例外，禁用使用真实 disabled，状态不只靠颜色表达 |
| 动效 | 不添加布局过渡和装饰动画，避免切换时丢失定位；保留原 0.7s 忙碌转圈；减少动态偏好下关闭非必要动画 |
| 深色原生控件 | 使用明确的 HTML `data-theme` 与根元素 `color-scheme`；手动选择优先，不能按系统偏好覆盖；不依赖较新的 `light-dark()` 才能正确显色 |
| 强制颜色 | 保留当前选中轮廓、导航下划线、开关边框和真实文字；清楚表达当前选项 |
| 日志 | 核心风格读取、切换、保存失败使用简短中文诊断；只记风格值和结果，不记 Key、账号、上游私有链接或用户数据路径 |

页面统一使用 `min-width:0`、`min-height:0` 和按容器限定的滚动。弹窗宽 500px、窗口四周至少 24px，最大高度为视口减 48px，内部可滚动；Escape、Tab 范围与关闭后焦点归还沿用现有实现。F/C toast 避开各自来源 dock/页脚，I 避开64px底部导航。

## 6. 素材、可实现性与验收

- F/C 只使用 CSS、系统本地字体与既有内联 SVG；I 继续使用正式 HTML 内嵌的 Instrument Serif 与 OFL 许可。三套不依赖外部 CDN、图片服务或新增库。
- Go 外壳＋同一 HTML 可表达上述 grid/flex 构图；macOS WKWebView 与 Windows WebView2 共用一份核心代码。F 的两种 blur 前缀和有色半透明面板提供可读基础；不要求原生系统材质或自绘窗口。
- 独立视觉评审使用同一虚构数据，先比三种概览与指定方向，再看四页、浅/深色、900×700 窄窗及必要空态/忙碌/弹窗；最多两轮，优先处理遮挡、层级和偏离基准的三项问题。
- 行为验证由新建 `gpt-6-luna` / `max` 子 agent 执行，只覆盖风格即切、持久化/旧配置/非法值、主题组合、草稿/焦点/滚动和受影响的 UI/管理服务回归；不读取真实 Key，不连接上游，不触发真实接管。
- 原生 select、系统 UI/宋体字体、滚动条和抗锯齿允许平台差异，不能把隔离 Chrome 截图等同于两种 WebView 实机验收。最终记录已验证与未验证平台；本次不打包、不 push。
