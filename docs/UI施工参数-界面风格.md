## 5. 共用行为与兼容

- 设置固定顺序：默认主题 / Gen Z 撞色 / Mintlify。浅深色仍独立保存；切换立即应用于四页、表单、弹窗、提示和焦点状态。
- 前后端仅接受 `layered`、`chaos`、`mintlify`。缺少字段、旧 `index`/`lexicon` 或非法缓存/服务值均回退 `layered`；旧皮肤不能再写入。保留其他配置字段，不操作Key或路由数据。
- 保存失败回滚到原皮肤；保存期间保留按钮焦点；保留 STYLE_REVISION 防旧轮询覆盖。页面、来源、搜索、模型勾选、图片输入、优先级、端口草稿、弹窗、焦点和合理滚动位置均沿用原行为。
- 新皮肤不改变 display、grid/flex、字体、字号、尺寸、间距、顺序或位置。默认布局规则不再按皮肤分支，颜色变量不能设置几何参数。
- 复用既有减少动态与强制颜色规则；不新增动画。核心应用、保存成功、失败和布局版本有中文诊断，只记录皮肤值和结果，不记录Key、账号或私有链接。
- 用户已拒绝 computeruse。本轮只执行指定 `gpt-6-luna` / `max` 子 agent 的非浏览器检查；静态样式/行为测试不冒充实际截图或两平台WebView验收。
